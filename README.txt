This is a project that can collect data from fitness watches. It processses and stores the data for the user to view later.
There are 3 main workout types, Hike, Run, and Walk. These are all stored separately so that users can track the type of workout they want.
Importing a workout must be in .gpx format, and currently it must also include speed, cadence and hr data.

Ultimately, the goal is to create a database for hikes that I can use to predict how long a hike will take by importing a .gpx file from AllTrails.
